# Student Performance Prediction Using Machine Learning

A Python and Streamlit project that analyzes student academic data and predicts expected final performance using Random Forest Regression.

## Modules
- Dashboard
- Data Analysis / EDA
- Performance Prediction
- Model Evaluation

## Technologies
Python, Pandas, NumPy, Scikit-learn, Matplotlib, Streamlit, CSV

## Run
```bash
python train_model.py
python -m streamlit run app.py
```
